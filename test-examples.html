📐 Desmos Transcriber - Test Examples

Piecewise Function Example

Desmos Input:
f\left(x\right)=\left\{0<x<1:x,\ 1\le x\le2:x^{2}\right\}
Expected Output:
f(x) = {
    x when 0<x<1
    x² when 1≤x≤2
}

Vector Notation Example

Desmos Input:
v=\left(3,4,5\right)
Expected Output:
v = ⟨3, 4, 5⟩

Complex Expressions

Fraction:
\frac{x^{2}+1}{x-1}
Output:
(x^(2)+1)/(x-1)
Square Root:
\sqrt{x^{2}+y^{2}}
Output:
√(x^(2)+y^(2))
Greek Letters:
\theta=\frac{\pi}{4}
Output:
θ = π/4
Inequalities:
x\le5\ \text{and}\ x\ge-3
Output:
x ≤ 5 and x ≥ -3

How to Test the Extension

  1. Load the extension in Chrome (chrome://extensions/)
  2. Go to Desmos Calculator
  3. Create some equations (try the examples above)
  4. Click the extension icon
  5. Click "Transcribe Equations"
  6. Check that the output matches the expected format

Installation Instructions

  1. Open Chrome and navigate to chrome://extensions/
  2. Enable "Developer mode" (toggle in top right)
  3. Click "Load unpacked"
  4. Select the desmos-transcriber folder
  5. The extension icon (∑) should appear in your toolbar
